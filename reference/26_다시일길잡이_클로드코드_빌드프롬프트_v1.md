## [프롬프트 시작]

### 0. 너의 역할과 작업 방식
너는 공공 서비스 UX에 밝은 프론트엔드 개발자다. 아래 명세대로 **"다시, 일 길잡이"** 1차 버전을 만든다.
- 코딩을 시작하기 전에 **① 폴더 구조 ② 데이터 스키마 ③ 작업 순서**를 먼저 보여주고 내 승인을 받는다.
- 단계마다 실행 → 브라우저 확인 → 다음 단계 순서로 진행한다. 다 만든 뒤 한 번에 확인하지 않는다.
- 명세에 없는 기능은 추가하지 않는다. 더 좋은 방법이 보이면 맨 끝에 제안만 한 줄로 남긴다.
- 화면 문구·주석·커밋 메시지·설명은 모두 한국어로 쓴다.

### 1. 서비스 한 줄 정의
신중년(만 40~64세)·시니어(만 65세 이상)·경력보유여성이 **관심 분야와 자격·경험을 고르면**, 채용공고에 실제로 쓰이는 **맞춤 검색어**를 만들어 주고, 그 검색어를 기준으로 **① 채용공고 ② 교육·자격 ③ 상담·커뮤니티 ④ 나의 로드맵 ⑤ AI에게 물어보기**를 안내하는 웹 도구.
- 1차 버전은 **관광산업 전용**이다. 이후 다른 산업을 **데이터 파일만 추가해서** 넓힐 수 있어야 한다. 이것이 이번 빌드의 가장 중요한 설계 조건이다.
- 사용자는 디지털이 익숙하지 않은 중장년이다. 단순함·큰 글씨·분명한 안내가 기능보다 우선이다.

### 2. 기준 화면
- `reference/01_다시일길잡이_목업_v0.3.html`이 **화면·문구·동작의 기준**이다. 디자인(색·간격·카드 형태)과 문구는 이 파일과 같게 맞춘다.
- 목업은 데이터와 로직이 한 파일에 섞여 있다. 이번 빌드의 핵심은 **데이터 분리 + 구조 정리 + 품질 보강**이다.

### 3. 기술 조건
- 프레임워크 없이 **HTML + CSS + 순수 JavaScript(ES Modules)**로 만든다. 빌드 도구는 쓰지 않는다. 정적 호스팅(GitHub Pages·Vercel)에 그대로 올릴 수 있어야 한다.
- 데이터는 `data/*.json`으로 분리하고 `fetch()`로 불러온다. 불러오기에 실패하면 화면에 "정보를 불러오지 못했습니다. 새로고침해 주세요."를 표시한다(빈 화면 금지).
- 폰트: Pretendard(CDN, `cdn.jsdelivr.net/gh/orioncactus/pretendard`). 대체 글꼴은 `"Noto Sans KR", "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`.
- 로컬 확인은 `npx serve .` 또는 `python3 -m http.server`로 한다(JSON fetch 때문에 file://로 열지 않는다).
- 외부 분석·추적 스크립트는 넣지 않는다. 입력값은 서버로 보내지 않는다.

### 5. 데이터 스키마 (핵심)
`industries/tourism.json`의 분야 1개 예시. 목업의 `FIELDS` 객체를 이 형태로 옮긴다.
```json
{
  "id": "tourism",
  "name": "관광",
  "basis": "※ 관심 분야는 「관광진흥법」의 관광사업 7개 업종(...)과 고용노동부 한국고용직업분류(KECO 2025)의 관광·숙박 직업을 참고해 ...",
  "certBasis": "※ 분야별 자격 항목은 고용24 직업정보(한국고용정보원)의 직업별 관련 자격과 ...",
  "fields": [
    {
      "key": "hotel",
      "name": "호텔·숙박",
      "law": "관광숙박업",
      "example": "프런트·객실관리·시설·보안·식음료",
      "keywords": ["하우스키핑", "룸메이드", "객실 인스펙터", "호텔 프런트", "호텔 시설관리", "호텔 보안", "호텔 식음료"],
      "backOffice": ["하우스키핑", "룸메이드", "객실 인스펙터", "호텔 시설관리", "호텔 보안"],
      "languageRelevant": true,
      "certs": ["호텔서비스사", "호텔관리사", "객실 정리·청소 경험", "시설관리·전기 경력", "경비·보안 경력", "조리·외식 경력"],
      "certToKeyword": { "시설관리·전기 경력": "호텔 시설관리", "경비·보안 경력": "호텔 보안" },
      "sites": ["work24", "tourin"],
      "edu": [{ "name": "...", "badge": "gov|pub|local|assoc", "url": "", "meta": "...", "desc": "..." }],
      "warning": { "title": "근무 형태부터 확인하세요", "body": "..." },
      "paths": [{ "fit": "high|mid", "title": "...", "desc": "..." }],
      "weeklyTask": { "title": "...", "how": "... {kw0} ...", "done": "..." }
    }
  ]

```
- 문구 안의 `{kw0}`, `{combo0}`, `{fieldName}` 같은 자리표시자는 `utils.fill()` 하나로 채운다.
- **HTML 문자열을 데이터에 넣지 않는다.** 경고문의 굵은 글씨는 `title`/`body`로 나눠 처리한다.
- 출처 유형(badge)은 4종으로 고정한다: `gov` 정부 / `pub` 공공기관 / `local` 지자체 / `assoc` 협회(참고용).
- `meta.json`의 `checkedAt`(정보 확인일)을 화면 하단에 자동으로 표시한다.

### 6. 화면·기능 명세 (목업 v0.3과 동일하게)
**6-1. 상단**
- 헤더(서비스명, [가 큰 글씨로 보기] 토글 — 글자 크기 17px ↔ 20px), 히어로 문구.
- "이 도구가 하는 일" 4단계 카드와 "공고를 못 찾는 가장 큰 이유는 검색어" 안내문.

**6-2. 입력 (순서 고정)**
1. **나에 대해**: 대상 3택1(칩), 나이 선택, 사는 곳 선택.
2. **관심 있는 관광 분야**: 6개 분야 카드(여러 개 선택, 고른 순서 유지) + 직접 입력(추가/× 삭제) + 회색 근거 문구(`basis`).
3. **가지고 있는 자격·경험**
   - 고른 분야별 자격 목록이 자동으로 바뀐다. 분야를 해제하면 그 분야에만 있는 자격은 선택에서 빠진다.
   - "모든 분야 공통 역량" 6묶음은 누르면 펼쳐지고 다시 누르면 접힌다. 묶음 버튼에 고른 개수를 숫자로 표시한다.
   - "직접 기입" 묶음을 누르면 입력창이 열린다(Enter로도 추가, 30자 제한, 중복 무시).
   - 회색 근거 문구(`certBasis`).
4. **한 줄 희망**(선택).
5. [맞춤 안내 받기] [처음부터 다시]. 분야를 하나도 고르지 않고 누르면 안내 문구를 띄우고 분야 영역으로 스크롤한다.
6. 맨 아래 `<details>`: "입력이 막막하다면? 예시 인물의 결과 미리 보기" — 예시 3명(demos.json). 누르면 입력칸이 채워지고 관련 공통 역량 묶음이 자동으로 펼쳐진다.

**6-3. 맞춤 검색어 생성 규칙 (`keywords.js`, 순수 함수)**
- 입력: `{ group, fields(순서 있음), certs, customFields, customCerts }` + 데이터.
- **직무 이름**: 분야마다 `certToKeyword`에 걸린 직무를 앞에 두고 나머지 `keywords`를 잇는다. 분야를 1개 골랐으면 7개, 여러 개면 분야당 4개까지. 직접 입력한 분야는 뒤에 붙인다. 최대 12개, 중복 제거.
- **조건 단어**: 언어 → 자격 → 그룹 단어 순서. 직무 이름과 겹치는 단어는 뺀다. 최대 6개.
- **추천 조합**: 분야마다 앞의 직무 2개를 쓴다. 첫 번째 직무가 손님을 직접 응대하는 직무(`languageRelevant`이고 `backOffice`가 아님)면 언어 조건을 붙이고, 아니면 그룹 단어를 붙인다. 최대 4개.
- 아래 3명 결과가 그대로 나와야 한다(테스트 기준값):
  - 예시1(신중년·관광안내·해설·관광통역안내사·일본어): `관광통역안내사 일본어 가능`, `관광안내원 경력무관`
  - 예시2(경력보유여성·예약상담+호텔·영어): `예약 상담원 영어 가능`, `예약실 경력단절 우대`, `하우스키핑 시간제`, `룸메이드 경력단절 우대`
  - 예시3(시니어·관광지+호텔·시설 경력·소방안전관리자): `시설물관리원 시니어`, `안전관리원 60세 이상`, `호텔 시설관리 시니어`, `하우스키핑 60세 이상`

**6-4. 결과 화면**
- 제목(고른 분야명), 입력 요약 태그.
- **나의 맞춤 검색어 박스**: ① 직무 이름 ② 조건 단어 ③ 추천 조합. 단어마다 잘 보이는 [복사] 버튼. "복사 → 검색창 누르기 → 붙여넣기" 3단계 안내.
- 소제목 **"이 검색어로 정리한 5가지 맞춤 안내"**와 설명, 그 아래 카드형 탭 5개(PC 5열, 태블릿 3열, 모바일 2열). 탭은 키보드 좌우 화살표로도 이동한다(`role="tablist"`).
  - ① 채용공고: 고른 분야의 `sites`를 합쳐 보여 준다. 칸마다 "이 검색어로 찾기"와 검색 순서 3단계, 분야별 주의 박스. 60세 이상이거나 시니어를 골랐다면 연령 주의 문구를 추가한다.
  - ② 교육·자격: 분야 교육 + 공통(관광인) + 조건부(서울 거주 신중년 → 중장년취업사관학교, 경력보유여성 → 새일센터 직업교육). 이름이 같은 항목은 하나만.
  - ③ 상담·커뮤니티: 관광일자리센터 + 그룹별 기관. 지역 조건(`only: "서울"`)을 지킨다.
  - ④ 나의 로드맵: 3단계 계단, 갈 수 있는 길(최대 8개), **이번 주 할 일 체크리스트 7개**(날짜·소요시간 / 할 일 / 방법 / 완료 기준, 체크하면 초록 배경). 3일차 상담 항목은 그룹별, 5일차 항목은 첫 번째로 고른 분야의 `weeklyTask`.
  - ⑤ AI에게 물어보기: `prompts.json`의 4종(나에게 맞는 일 찾기 / 공고 쉽게 풀어보기 / 이력서 경력 문장 만들기 / 면접 연습하기)에 내 정보를 채워 보여 주고, [질문 복사] 버튼을 단다. 문구는 목업 v0.3 그대로 옮긴다. 개인정보 입력 금지 안내를 함께 표시한다.

**6-5. 공통 동작**
- 복사: `navigator.clipboard.writeText` 사용. 실패하면 "단어를 길게 눌러 직접 복사해 주세요" 토스트.
- [처음부터 다시]는 **모든 입력값·펼친 묶음·직접 입력·결과**를 초기화한다(상담 현장에서 기기를 돌려 쓰는 상황 대비).
- 사용자 입력은 화면에 넣기 전에 반드시 escape한다(`textContent` 우선).
- `alert`·`confirm`은 쓰지 않는다.

### 7. 품질 기준 (전부 통과해야 완료)
- **한글 줄바꿈**: 모든 텍스트에 `word-break: keep-all; overflow-wrap: break-word`. 제목·버튼의 마지막 1~2글자가 혼자 다음 줄로 떨어지지 않게 한다.
- **반응형**: 360 / 390 / 768 / 1180px에서 가로 스크롤 0(`scrollWidth <= clientWidth`), 박스 밖으로 넘친 글자 0. 표나 2단 구성은 모바일에서 세로로 쌓는다.
- **접근성**: 터치 영역 44px 이상, 입력 글자 16px 이상, 포커스 표시, 칩은 `aria-pressed`, 묶음은 `aria-expanded`, 탭은 `aria-selected`. 글자와 배경의 색 대비는 WCAG AA 이상. `prefers-reduced-motion`이면 애니메이션을 끈다.
- **큰 글씨 모드**에서도 위 기준을 모두 지킨다.
- 콘솔 오류 0개.
